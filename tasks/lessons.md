# Уроки

- Новый JS-файл игры добавляй в 4 места: index.html, pages.yml (node --check и cp), загрузчик tests/game.test.cjs. Иначе GitHub Pages соберётся без него.
- Классические скрипты делят одну глобальную лексическую область: `const`/`let` с одинаковым именем в двух файлах дают SyntaxError. Общие константы (canvas, ctx, W, H, VIEW, FOV) объявлены только в renderer.js, хелперы модулей живут внутри IIFE.
- Для сравнения скриншотов эталон снимай тем же скриптом с HEAD (git archive в scratchpad + отдельный порт), а не сохранёнными заранее PNG: анимации спрайтов зависят от способа съёмки.
- В worktree-режиме агенты живут в .claude/worktrees/ внутри репозитория. Держи её в .gitignore, иначе `git add -A` захватит вложенные репозитории.
- Агенты в worktree симлинкуют node_modules; запрещай им `git add -A` (только по именам файлов) и сразу проверяй `git show --stat` перед слиянием. Иначе симлинк попадёт в коммит, и при слиянии git удалит настоящий node_modules.
- Без сети `npm run test:browser` зависает на `page.goto`: style.css импортирует Google Fonts и событие load ждёт DNS. Для локальной проверки офлайн отдавай зеркало сайта со style.css без `@import` (webServer.cwd во временном конфиге), сам тест не меняй.
- Поток `<audio>` стартует за доли секунды, только если его запрос не стоит в очереди за пачкой fetch(): сначала первые секунды музыки, потом клипы.
