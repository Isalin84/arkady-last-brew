# Уроки

- Новый JS-файл игры добавляй в 4 места: index.html, pages.yml (node --check и cp), загрузчик tests/game.test.cjs. Иначе GitHub Pages соберётся без него.

- Для сравнения скриншотов эталон снимай тем же скриптом с HEAD (git archive в scratchpad + отдельный порт), а не сохранёнными заранее PNG: анимации спрайтов зависят от способа съёмки.
